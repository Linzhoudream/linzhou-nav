## 脚本 A：对比/平替 — "129 vs 1299 托特包，差在哪？"

```
类型：对比/平替
时长：35-40秒
平台：抖音 / 小红书 / TikTok
制作：AI概念图 + 大牌产品截图 + 剪辑
难度：⭐⭐
```

### 分镜

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[0-3秒] 钩子 — 价格冲击

画面：分屏
  左边：一只简约托特包（AI概念图，奶咖色）
  右边：一只大牌托特包（官网截图）
  中间大字弹出价格：
    左：¥129          右：¥1299
    价格差10倍！

配音："129和1299的托特包，差在哪？"
BGM：悬疑对比音效，咚的一声
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[3-6秒] 第一轮PK — 材质

画面：快速切入材质特写对比
  左：AI概念图放大面料纹理 — 字幕弹出"防泼水帆布"
  右：大牌官网面料图 — 字幕弹出"帆布"
  左画面边缘加绿色勾✅

配音："先说材质——这边129的，防泼水帆布，下雨抖一抖就干。"
      "那边1299的……帆布，沾水就留印。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[6-12秒] 第二轮PK — 分区系统

画面：打开包内部对比（俯拍）
  左：AI生成收纳内胆展示 — 电脑仓/干湿袋/快取口袋 依次弹出标签
  右：大牌包内部 — 一个大口袋，字幕"一个黑洞"
  左画面三个绿色勾✅✅✅

配音（加速）："再看里面——129的包，电脑独立仓、水杯干湿分离袋、
              钥匙手机快取口袋、可拆卸收纳内胆。"
      "1299的包——一个大口袋。就一个大口袋。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[12-18秒] 第三轮PK — 背法

画面：背法对比
  左：AI生成三种背法展示（手提/单肩/斜挎）— 快速切换
  右：大牌模特图 — 只能手提
  左画面弹出"三背法"

配音："129的，手提/单肩/斜挎，一包三背。"
      "1299的，只能手提，肩带还不能拆。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[18-25秒] 补刀 — 终极暴击

画面：
  大牌包的价格标签被一个红色大叉❌划掉
  屏幕切换到AI概念图的四个颜色并排展示
  （雾灰/奶咖/橄榄绿/浅奶茶）

配音（放慢，像在跟朋友聊天）："说实话，1299那个，钱都花在牌子上了。
      这个129的，钱花在——防水面料、收纳系统、三背法设计上。"
      "你选哪个？"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[25-30秒] CTA

画面：产品全景，弹出"¥129"
配音："评论'收纳'，我把链接发给你。"
字幕（大字）："评论'收纳' 发链接👇"
```

## 脚本 B：产品拟人化 — "一个托特包的内心独白"

```
类型：产品拟人化/产品说话
时长：30-35秒
平台：抖音 / 小红书
制作：AI概念图 + AI生成卡通表情 + 配音软件
难度：⭐⭐⭐
```

### 角色设定

- **主角**：一个"饱经摧残"的普通托特包（配音：委屈、带点幽默）
- **配角**：一个"从容优雅"的收纳系统托特包（配音：淡定、带点得意）
- **表情**：用AI生成两个简单的卡通眼睛+嘴巴，贴在包的照片上

### 分镜

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[0-3秒] 钩子

画面：一个被塞得鼓鼓囊囊的普通托特包，表情是 😩（卡通眼睛嘴巴）
配音（委屈+吐槽语气）："我是一个托特包。我主人每天往我肚子里塞——
      电脑、雨伞、饭盒、化妆包、运动鞋、三瓶水、一把伞、还有半包薯片。"
字幕随配音逐条弹出物品清单
BGM：轻快的喜剧音效
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[3-8秒] 痛苦展示

画面：快速切换包的"痛苦瞬间"
  镜头1：包被塞得拉链拉不上（卡通表情 😫）
  镜头2：下雨天包被淋湿（卡通表情 😭）
  镜头3：主人在包里翻找钥匙翻了半天（卡通表情 😵）

配音（越来越崩溃）："拉链崩开过。下雨淋透过。主人每天在我肚子里捞钥匙，
      跟大海捞针似的。我太难了。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[8-13秒] 转折 — 另一个包出场

画面：画面一转，一只收纳系统托特包从容出场
  表情是 😎（淡定+一点点得意）
  包的收纳内胆、电脑仓、干湿袋清晰可见

配音（普通包，惊讶）："然后有一天，我遇到了隔壁工位的包。"
配音（收纳包，淡定）："我家主人东西也不少啊。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[13-22秒] 收纳包"凡尔赛"展示

画面：收纳包依次展示分区
  镜头1：电脑滑进独立仓（配音："电脑有自己房间"）
  镜头2：水杯扣进干湿袋（配音："水杯住单间，漏了也不怕"）
  镜头3：收纳内胆打开，三个分区整整齐齐（配音："杂物各有各的格子"）
  镜头4：手机一秒从侧袋取出（配音："手机随取随用"）

配音（收纳包，越来越得意）："我家主人说，电脑有自己房间，水杯住单间漏了也不怕，
      杂物各有各的格子，手机一秒快取。我嘛，就负责保持体面。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[22-28秒] 普通包破防

画面：切回普通包，表情变成 😳 → 😢
配音（普通包，小声）："……同样是托特包，差别咋就这么大呢？"
字幕弹出："同样是托特包，差别咋就这么大呢？"

画面：收纳包表情 😏，弹出价格标签"¥129"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[28-32秒] CTA

画面：收纳包四个颜色并排，各自有不同的可爱表情
配音（收纳包，对观众说）："想让你家包也过上好日子？
      左下角，129块，带一个收纳系统回家。"
字幕："¥129 · 四色可选 · 左下角👇"
```

### 制作要点

```
需要准备的素材：
1. AI概念图（已有）— 包的正面照、内部俯拍、各分区特写
2. 卡通表情 — 用Canva/AI生成简单的眼睛嘴巴，贴在包的照片上
3. 配音 — 用剪映文字转语音或AI配音工具
   - 普通包：委屈/吐槽语气（女声，年轻化）
   - 收纳包：淡定/得意语气（女声，稍微成熟一点）
4. 剪辑 — 剪映即可，关键是把两个包的"对话"节奏做出来
```

## 脚本 C：古人穿越 — "唐代仕女收到了一个现代包"

```
类型：古人穿越/时空反差
时长：35-40秒
平台：抖音 / B站 / 小红书
制作：AI生成古代场景 + 包的概念图 + 合成
难度：⭐⭐⭐⭐
```

### 角色设定

- **唐代仕女**：AI生成（Midjourney/可灵），身着唐装，梳高髻
- **现代包**：「一包走」收纳托特包（AI概念图）

### 分镜

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[0-3秒] 钩子

画面：AI生成的唐代庭院场景，一个仕女坐在石凳上
      突然一道光闪过，一个托特包凭空出现在她面前的石桌上
      仕女吓了一跳，瞪大眼睛

字幕（大字）"如果唐朝人收到了一个现代托特包……"
BGM：古风音乐 + 突然一个现代音效（光的咻~声）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[3-8秒] 初次打量

画面：仕女小心翼翼地拿起包，翻来覆去地看
  镜头给到包的面料特写（AI概念图放大）
  仕女摸了摸面料，露出疑惑的表情

配音（仕女，内心独白，带古风腔）："此物……无绣无锦，无金无玉，
      面料却柔韧异常。这是何物？"
字幕弹出："防泼水帆布"（用毛笔字体）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[8-16秒] 发现分区 — 核心惊喜

画面：仕女打开包，发现里面别有洞天
  慢镜头展示：
  - 手指碰到电脑仓 → 字幕弹出"暗格？"
  - 摸到干湿分离袋 → 字幕弹出"另有乾坤？"
  - 拉开收纳内胆 → 字幕弹出"机关重重！"
  仕女表情从疑惑→惊讶→欣喜

配音（语速加快）："此物内藏玄机！有暗格、有隔层、还有……机关重重！
      一个布袋竟能分门别类、各归其位！"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[16-22秒] 开始试用

画面：仕女兴奋地把自己的物品放进去
  镜头1：把一卷竹简放进电脑仓（正好合适）— 仕女惊喜
  镜头2：把一个瓷瓶水壶扣进干湿袋 — 仕女拍手
  镜头3：把小铜镜和胭脂盒放进快取口袋 — 仕女频频点头
  镜头4：把披帛（唐代丝巾）叠好放进主仓

配音："竹简有专位！水壶不漏！铜镜胭脂随手可取！
      连妾身的披帛都能整齐收纳。"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[22-28秒] 出门展示

画面：仕女背上包（斜挎），走在长安街上
  背景是AI生成的唐代街景（建筑、路人）
  路过的其他仕女纷纷回头，窃窃私语
  仕女昂首挺胸，非常得意

配音（仕女，得意）："背着它走在长安街上，连公主都问我——
      此物何处可得？"
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[28-35秒] 穿越回现代 — CTA

画面：画面一转，回到现代
  一个现代女生背着同款包走在城市街道上
  画面分屏：
    左边：唐代仕女背着包走在长安街
    右边：现代女生背着包走在都市街道

配音："一千年前就想有的收纳智慧。今天，129元。"
字幕："穿越千年的收纳系统 · ¥129 · 左下角👇"

画面：四个颜色并排，配毛笔字体颜色名
  雾灰 / 奶咖 / 橄榄绿 / 浅奶茶
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 制作要点

```
需要准备的素材：
1. AI古代场景（Midjourney/可灵生成）：
   - Prompt: "Tang Dynasty Chinese courtyard, elegant noblewoman in traditional 
     hanfu sitting on stone bench, ancient Chinese architecture, cherry blossoms,
     cinematic lighting, historical drama style --ar 9:16"
   - Prompt: "Tang Dynasty Chang'an street scene, ancient Chinese city, 
     market stalls, pedestrians in traditional clothing, historical atmosphere 
     --ar 9:16"
   
2. AI仕女人物（用可灵的"图生视频"功能或Midjourney角色一致性）
   
3. 包的概念图（已有）
   
4. 合成方式：
   - 方案A（简单）：把包的概念图PS到古代场景中，做成幻灯片式+配音
   - 方案B（进阶）：用可灵AI的"图生视频"让仕女"动起来"，包也做动态合成
   - 方案C（最简单）：AI静态图 + 剪映关键帧动画 + 配音

5. 配音：剪映文字转语音或专业AI配音，仕女用"温婉古风"声线
```

## 三种脚本对比总结

| 维度 | 🅰️ 对比/平替 | 🅱️ 产品拟人化 | 🅲 古人穿越 |
|------|:--:|:--:|:--:|
| 爆款潜力 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 制作难度 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ |
| 制作时间 | 2-3小时 | 3-4小时 | 4-6小时 |
| AI工具需求 | 概念图 + 剪辑 | 概念图 + 表情 + 配音 | 古代场景 + 人物 + 合成 |
| 转化直接度 | 最高 | 中高 | 中（偏品牌） |
| 二次传播力 | 高 | 极高 | 极高 |
| 适合平台 | 抖音/TikTok | 抖音/小红书 | 抖音/B站/小红书 |

---

## 推荐执行顺序

```
第一周：
  Day 1-2：做 🅰️对比/平替（最简单，先跑起来）
  Day 3-4：做 🅱️产品拟人化（最有趣，测试传播力）
  Day 5-6：做 🅲古人穿越（最惊艳，冲击品牌感）

发布节奏：
  每天1条，三个平台同步（抖音/小红书/TikTok）
  三天后看数据，哪个方向互动最高
  下周加倍投入那个方向
```
