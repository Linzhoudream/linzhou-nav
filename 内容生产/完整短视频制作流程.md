
从零到成片，一般分 **6 个阶段**：### 1. 策划选题这是决定成败的一步，很多人跳过直接写脚本，结果拍完没流量。- **选品/选题**：判断内容是否有爆款基因（反差、痛点、猎奇、身份认同）- **竞品扫描**：同类视频怎么拍的、什么结构、评论区在问什么- **人群画像**：给谁看、在哪发布（抖音竖屏9:16 / B站横屏16:9）- **核心钩子设计**：前3秒必须留住人，这决定80%的完播率> 我们这次做的"猫咪委屈→太空舱豪宅"就是典型的 **痛点+反差+身份投射** 三合一钩子。### 2. 脚本撰写把钩子扩展成完整叙事结构，落地到时间码。- **结构公式**：钩子(0-3s) → 反转(3-7s) → 卖点展示(7-13s) → SKU扩展(13-17s) → CTA收尾(17-20s)- **台词打磨**：字数必须匹配时间槽容量，不然生成时会超载被驳回- **每镜只做一件事**：信息密度过高观众反而什么都没记住- **视角选择**：第一视角拟人配音（我们用的猫视角）、第三视角旁白、口播直述——不同视角决定代入感### 3. 素材与分镜把文字脚本翻译成可执行的视觉蓝图。- **产品图/参考图入库**：保证产品外观跨镜一致- **生成首帧图**：每个镜头的起始定格画面，是视频生成的"种子"- **（可选）尾帧图**：需要平滑转场时才生成- **分镜写入**：prompt + 时长 + 帧图素材名 + 转场标记，全部预检通过才算锁稿> 首帧图质量直接决定生成视频的质量。画面模糊、构图混乱，生成的视频也救不回来。### 4. 视频生成逐镜把首帧图"演活"成视频片段。- **逐镜生成**（推荐）：一条一条做，随时检查质量，不合格只重做单镜- **批量生成**：一次性出全部，省时间但出问题要整批排查- **生成后质检**：动作是否连贯、产品是否走形、台词节奏是否对味- **不合格重做**：换首帧图或调prompt，只重新生成问题镜头### 5. 后期合成把零散片段组装成有节奏感的成片。- **BGM/配乐**：选曲、卡点、音量曲线（带货视频BGM要轻，别压过台词）- **配音/TTS**：如果视频模型没自带语音，后期补录旁白- **字幕**：台词上字、关键词高亮、CTA大字- **轨道编排**：裁掉废帧、调整节奏、变速、画面衔接微调- **产品细节补强**：透气孔特写、材质肌感等画面如果生成时没体现，可以在这里插入额外片段### 6. 交付发布- **合成工程文件**（.cvp）：确认轨道无误后一键合成- **发布前终检**：全片播一遍，检查音画同步、字幕无遮挡、CTA清晰- **多平台适配**：同一素材可出9:16竖屏版和16:9横屏版|
