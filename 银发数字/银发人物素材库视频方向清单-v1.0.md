## 二、跨图组合方案（核心卖点）

### 组合1 · 时间轴成长史（最强组合）

**素材**：004校园 → 003街景 → 002中年 → 001老院
**叙事**："一个保定人的人生四幕"

```
00:00-00:03 校园青年（18岁）
  文案：那年高考完，我说要离开保定
00:03-00:06 街景青年（25岁）
  文案：我在城市街头，想起了老院的槐树
00:06-00:09 室内中年（40岁）
  文案：孩子问我，爸爸你年轻时长啥样
00:09-00:12 老院大叔（55岁）
  文案：回到老院，才发现这辈子最想的还是家
00:12-00:15 四张图叠化+字幕
  CTA：你的一生，值得被记录
```

**适用**：抖音/视频号（完播率极高）  
**变现**：家族记忆档案定制（99-299元）  
**技术**：静态图→动态化（每张图3秒微动）→转场叠化→字幕  
**合规**：AI标注 + 肖像授权（如用真实人物）
