# 银发内容生产体系 · 方法论手册

> 面向中老年短视频赛道的AI内容生产方法论
> 覆盖：叙事语法 / 场景替换 / 情绪钩子 / 平台差异化 / 质检清单
> 适用于：银发IP运营 / 中老年内容创业 / 本地生活服务宣传

---

## 一、固定底盘（个人IP的"不变"）

### 1.1 视觉DNA

- **地理锚**：本地不可复制的场景元素（如：老街道/土坯院/本地产业地标）
- **方言锚**：当地方言词（如："整明白""弄利索""咱爸咱妈"）
- **人物锚**：真实皱纹保留、不磨皮假面、真实老人出镜
- **色调锚**：真实记录轨=自然光/暖黄怀旧；AI创意轨=电影级布光/冷暖对比

### 1.2 人设腔调

| 维度 | 固定写法 |
|------|---------|
| 身份 | 本地产业顾问 / 银发数字生活设计师 |
| 语气 | 当地方言+短句≤15字 |
| 结尾 | 必须有行动指令（"下一步干什么"） |
| 禁用词 | 众所周知/值得注意的是/综上所述（AI味黑名单） |

### 1.3 双轨结构

```
TrackA 真实记录轨（信任底座）= 60%产出
TrackB AI创意轨（变现引擎）= 40%产出
```

### 1.4 合规框架

- T0-T4分级
- 禁用词清单（广告法极限词/医疗宣称/诈骗暗示）
- AI标注义务
- 肖像授权

### 1.5 画质锚（尾部固定）

```
8K / 超写实摄影 / PBR物理渲染 / 光线追踪 / 景深虚化 / HDR / 电影级布光
```

### 1.6 质检清单6件套

1. 竖屏9:16
2. 无遮挡主体
3. 无烤字/水印
4. 真实感增强
5. 色彩校正
6. 英文锚词强制（尾部）

## 二、可变创新（每周轮换的"变"）

### 2.1 叙事语法轮换（6种类型每周切换）

从视频模板库提取的6种叙事语法：

| 周次 | 叙事语法 | 适用场景 | 银发适配示例 |
|------|---------|---------|-------------|
| W1 | IP短片（微缩世界冒险） | 情感故事 | 老人穿越回年轻时的本地街头 |
| W2 | 创意动态化（多镜头叙事） | 视觉冲击 | 老照片→彩色→动态的层层展开 |
| W3 | 海报动画（产品登场） | 商品/服务 | AI圆梦服务介绍短片 |
| W4 | 商业TVC（飞行穿梭） | 品牌故事 | "一个本地人一生的产业" |
| W5 | 解构动画（零部件拆解） | 知识科普 | 防诈骗步骤拆解 |
| W6 | 口播带货（自动生成口播） | 推荐种草 | "这款老照片修复，我给我妈试了" |

**轮换规则**：每周一自动从6种中选1种（按档期匹配），确保6周内不重复。

### 2.2 场景替换库（8场景每周轮换）

从产业模板迁移到银发的8场景：

| 场景ID | 场景名 | 情绪基调 | 关键元素 |
|--------|--------|---------|---------|
| S1 | 老院日常 | 乡愁/怀旧 | 土坯墙/压水井/老槐树 |
| S2 | 客厅温情 | 亲情/陪伴 | 沙发/电视/全家福 |
| S3 | 街头回忆 | 青春/变迁 | 老街道/自行车 |
| S4 | 节日团圆 | 喜庆/团圆 | 月饼/饺子/灯笼 |
| S5 | 手艺作坊 | 传承/匠心 | 裁料/油边/缝制 |
| S6 | 跨时空对比 | 震撼/圆梦 | 年轻vs老年同框 |
| S7 | 社交传播 | 互动/转发 | 家族群/朋友圈/点赞 |
| S8 | 情绪兜底 | 留白/治愈 | 夕阳/背影/空镜 |

**轮换规则**：每条提示词至少含1个场景，每周主推2个场景。

### 2.3 情绪钩子轮换（6类钩子每周轮换）

| 周次 | 钩子类型 | 模板句 |
|------|---------|--------|
| W1 | 痛点钩子 | 老乡亲，这种骗局千万别碰！ |
| W2 | 乡愁钩子 | 还记得早年赶集、做手艺的日子吗？ |
| W3 | 反差钩子 | 人退休后，最错的就是天天躺着 |
| W4 | 共情钩子 | 人老了，最惦记的还是老家小院 |
| W5 | 圆梦钩子 | 妈，我终于帮您找回年轻时的样子了 |
| W6 | 修复钩子 | 几十年的老照片，今天让它重新动起来 |

### 2.4 音乐/音效库（10套预置）

- **国风温情**：古筝+笛子+轻柔鼓点 → 乡愁/圆梦
- **怀旧钢琴**：单钢琴+环境音（蝉鸣/风声） → 老照片活化
- **励志电子**：轻电子+人声哼唱 → 老年逆袭/正能量
- **节日喜庆**：锣鼓+民乐 → 春节/中秋
- **治愈白噪音**：雨声+钢琴 → 失眠/养生
- **本地老调**：地方戏曲片段 → 本地文化
- **怀旧金曲**：80年代流行歌曲变奏 → 青春回忆
- **悬疑紧张**：低音弦乐+心跳声 → 反诈科普
- **温馨民谣**：吉他+口琴 → 祖孙日常
- **史诗交响**：弦乐+铜管 → 人生回顾/大场面

### 2.5 平台差异化分镜（3套模板）

| 平台 | 分镜节奏 | 时长 | 特殊要求 |
|------|---------|------|---------|
| 抖音 | 快-快-快（每2秒变化） | 15-30秒 | 前3秒必须有视觉冲击 |
| 快手 | 中-快-中（留气口） | 20-45秒 | 方言配音加分 |
| 视频号 | 慢-中-慢（情感递进） | 30-60秒 | 家族群传播，结尾留转发钩子 |

## 三、人物底图库构建指南

### 3.1 底图库构成建议

建议拍摄/收集以下年龄段的人物底图：

| 年龄段 | 场景 | 服装 | 表情 |
|--------|------|------|------|
| 青年（18-25岁） | 校园/街景 | 牛仔/校服 | 青涩/期待 |
| 青年（22-28岁） | 城市街景 | 牛仔/休闲 | 忧郁/希望 |
| 中年（35-45岁） | 客厅/办公室 | 针织衫/工装 | 沉稳/责任 |
| 老年（50-60岁） | 老院/作坊 | 夹克/工装 | 温和/沧桑 |
| 高龄（80岁+） | 同场景 | 同服装（变老版） | 慈祥/平和 |

### 3.2 姿势变换规则

按叙事语法自动调整姿势：
- **IP短片叙事** → 戏剧性姿势（行走/回头/穿越/惊讶）
- **海报动画** → 展示性姿势（站立微笑/手持道具/正面半身）
- **商业TVC** → 正式姿势（站姿挺拔/手势引导/眼神坚定）
- **解构动画** → 步骤式姿势（动作分解/手部特写/指示性动作）
- **口播带货** → 对话式姿势（对镜头说话/自然手势/手持产品）

### 3.3 服饰随场景变换

| 场景 | 服装 |
|------|------|
| 老院日常 | 朴素夹克/工装 |
| 客厅温情 | 针织衫/居家服 |
| 街头回忆 | 牛仔/休闲装 |
| 节日团圆 | 中式唐装/红色元素 |
| 手艺作坊 | 围裙/工装/沾油工作服 |

## 四、提示词工程规范

### 4.1 图片提示词结构

```
【中文主导描述】
本地场景，年龄段+地域男人/女人，发色特征，
面部真实皱纹和老年斑保留，服装描述，
姿势描述，道具描述，
光线描述，氛围描述，
8K超写实摄影，PBR物理渲染，光线追踪，
景深虚化，HDR，电影级布光。
竖屏9:16。禁止磨皮，禁止塑料皮肤，禁止美颜滤镜。
保留每一条皱纹和老年斑。

【英文锚词（尾部固定）】
photorealistic, ray-traced, PBR, HDR, cinematic lighting
```

### 4.2 视频提示词结构（时间轴分镜）

```
[00:00-00:03] 开场描述
运镜：运镜动词（推/拉/摇/移/跟拍/环绕/升降）
节奏：慢/中/快

[00:03-00:06] 发展描述
运镜：...
转场：动作匹配/主体遮挡/镜头穿越/光影转场...
节奏：...

[00:06-00:10] 高潮描述
...

[00:10-00:12] 收尾描述
...
```

### 4.3 配音文案规范

- 保定大白话（或当地方言），每句≤15字
- 含≥1个方言词
- 结尾有行动指令
- 结尾有情绪兜底（"别太折腾"类）

### 4.4 CTA字幕规范

- 超大字、短句、白底黑边
- 无闪光/叠层特效
- 人像轻度美化保留真实纹路

## 五、平台差异化执行手册

### 5.1 抖音版（快节奏）

```
前3秒：视觉冲击（分屏/对比/强色彩）
3-8秒：快速切换3个画面
8-12秒：情感高潮+CTA
BGM：快节奏/卡点/电子
```

### 5.2 快手版（中节奏）

```
前3秒：方言钩子（"老乡亲，你们有没有..."）
3-10秒：故事展开，留气口
10-20秒：情感递进+CTA
BGM：民谣/老歌/地方戏曲
```

### 5.3 视频号版（慢节奏）

```
前5秒：空镜+环境音（建立氛围）
5-20秒：情感故事娓娓道来
20-30秒：情感高潮+转发钩子（"转给家里老人看看"）
BGM：钢琴/弦乐/环境白噪音
```

## 七、定时任务配置模板

### 7.1 执行频率

```
每周一 09:00 执行一次
预计耗时：10-15分钟
```

### 7.2 执行步骤

```
Step 1 市场扫描 → 判断当期情绪
Step 2 选择叙事语法 → 从6种中选1种
Step 3 选择场景组合 → 从8场景中选2个
Step 4 选择钩子类型 → 从6类中选1个
Step 5 选择BGM → 从10套中选1套
Step 6 匹配人物底图 → 按姿势/服饰变换规则
Step 7 生成5套提示词包（2真实记录+2AI创意+1封面）
Step 8 合规检查
Step 9 输出到文档库+备份
Step 10 推送通知
```

### 7.3 失败降级

- 搜索无新热点 → 出"深度版"老热点
- 算力耗尽 → 自动降级为3条核心提示词
- 底图读取失败 → 改用纯文生图，标注"本周无参考图"
