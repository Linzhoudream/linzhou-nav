# 银发内容"固定底盘+可变创新"配方 v2.0

> 基于6份模板库深度拆解 + 个人IP特色锚定 + 定时任务防僵化机制
> 解决核心问题："定时任务会不会一直套模板？创新线怎么变？"

---

## 一、问题诊断：之前的设计缺了什么

| 缺失项 | 之前设计 | 问题 |
|--------|---------|------|
| 叙事语法轮换 | 只用一套分镜结构 | 每周出片"长得像"，观众审美疲劳 |
| 模板库调用 | 没真正读取他人模板内容 | 提示词库是"闭门造车"，没吸收外部创新 |
| 场景替换机制 | 固定几个场景反复用 | 老院/竹林出现太频繁，IP感弱化 |
| 音乐/音效库 | 没建立 | 每次重新想BGM，效率低 |
| 平台差异化 | 粗略区分 | 抖音/快手/视频号的分镜节奏没有差异化模板 |
| 个人特色锚点 | 模糊 | "保定大白话"是特色，但没固化到模板里 |

## 二、固定底盘（个人IP的"不变"）

### 底盘1：视觉DNA（永远不变）

```
【保定本地不可复制元素】
- 地理锚：白沟箱包城/保定老街道/农村土坯院/老槐树/压水井
- 方言锚："整明白""弄利索""咱爸咱妈""老姐妹""呵"
- 人物锚：真实皱纹保留、不磨皮假面、保定老人真实出镜
- 色调锚：真实记录轨=自然光/暖黄怀旧；AI创意轨=电影级布光/冷暖对比

【质检红线】
- 每条提示词必须含"保定"或"河北"或"白沟"至少一个地理锚
- 禁用卖家腔（"源头工厂价""赶紧下单"）→ 发现就重写
- 顾问腔固定句式："值不值得入手，看你怎么判断""评论区说说你怎么看"
```

### 底盘2：人设腔调（永远不变）

| 维度 | 固定写法 | 来源 |
|------|---------|------|
| 身份 | 白沟产业带顾问 / 银发数字生活设计师 | 用户画像 |
| 语气 | 保定大白话+短句≤15字 | 表达习惯 |
| 结尾 | 必须有行动指令（"下一步干什么"） | 内容规范 |
| 禁用词 | 众所周知/值得注意的是/综上所述 | AI味黑名单 |

### 底盘3：双轨结构（永远不变）

```
TrackA 真实记录轨（信任底座）= 60%产出
TrackB AI创意轨（变现引擎）= 40%产出
```

### 底盘4：合规框架（永远不变）

```
T0-T4分级 + 禁用词清单 + AI标注义务 + 肖像授权
```

### 底盘5：画质锚（永远不变）

```
8K / 超写实摄影 / PBR物理渲染 / 光线追踪 / 景深虚化 / HDR / 电影级布光
```

## 三、可变创新（每周轮换的"变"）

### 创新维度1：叙事语法轮换（6种模板类型每周切换）

从"豆包生视频模板"提取的6种叙事语法：

| 周次 | 叙事语法 | 适用场景 | 银发适配 | 示例 |
|------|---------|---------|---------|------|
| W1 | IP短片（微缩世界冒险） | 情感故事 | ⭐⭐⭐⭐⭐ | 老人穿越回年轻时的保定街头 |
| W2 | 创意动态化（多镜头叙事） | 视觉冲击 | ⭐⭐⭐⭐ | 老照片→彩色→动态的层层展开 |
| W3 | 海报动画（产品展示） | 商品/服务 | ⭐⭐⭐ | AI圆梦服务介绍短片 |
| W4 | 商业TVC（飞行穿梭） | 品牌故事 | ⭐⭐⭐⭐ | "一个保定人一生的包"（箱包+人生） |
| W5 | 解构动画（零部件拆解） | 知识科普 | ⭐⭐ | 防诈骗步骤拆解 |
| W6 | 口播带货（自动生成口播） | 推荐种草 | ⭐⭐⭐ | "这款老照片修复，我给我妈试了" |

**轮换规则**：每周一自动从6种中选1种（按档期匹配），确保6周内不重复。

### 创新维度2：场景替换库（8场景每周轮换）

从"白沟箱包工具箱"迁移到银发的8场景：

| 场景ID | 场景名 | 原始来源 | 银发适配 | 情绪基调 |
|--------|--------|---------|---------|---------|
| S1 | 老院日常 | 白沟工厂变体 | 压水井/老槐树/土坯墙 | 乡愁/怀旧 |
| S2 | 客厅温情 | 咖啡馆变体 | 沙发/电视/全家福 | 亲情/陪伴 |
| S3 | 街头回忆 | 通勤变体 | 保定老街道/自行车 | 青春/变迁 |
| S4 | 节日团圆 | 封面变体 | 中秋月饼/春节饺子 | 喜庆/团圆 |
| S5 | 手艺作坊 | 工厂变体 | 裁料/油边/缝制 | 传承/匠心 |
| S6 | 跨时空对比 | 对比变体 | 年轻vs老年同框 | 震撼/圆梦 |
| S7 | 社交传播 | 包挂变体 | 家族群/朋友圈/点赞 | 互动/转发 |
| S8 | 情绪兜底 | 情绪变体 | 夕阳/背影/空镜 | 留白/治愈 |

**轮换规则**：每条提示词至少含1个场景，每周主推2个场景，避免审美疲劳。

### 创新维度3：情绪钩子轮换（6类钩子每周轮换）

从V2.0技能说明书提取：

| 周次 | 钩子类型 | 模板句 | 适用叙事语法 |
|------|---------|--------|-------------|
| W1 | 痛点钩子 | 保定老乡亲，这种骗局千万别碰！ | 解构动画 |
| W2 | 乡愁钩子 | 还记得早年白沟赶集、做箱包的日子吗？ | IP短片 |
| W3 | 反差钩子 | 人退休后，最错的就是天天躺着 | 创意动态化 |
| W4 | 共情钩子 | 人老了，最惦记的还是老家小院 | IP短片 |
| W5 | 圆梦钩子 | 妈，我终于帮您找回年轻时的样子了 | 商业TVC |
| W6 | 修复钩子 | 几十年的老照片，今天让它重新动起来 | 创意动态化 |

### 创新维度4：音乐/音效库（预置10套）

从"竹林剑舞"模板提取的BGM设定法：

```
【国风温情】古筝+笛子+轻柔鼓点 → 乡愁/圆梦内容
【怀旧钢琴】单钢琴+环境音（蝉鸣/风声） → 老照片活化
【励志电子】轻电子+人声哼唱 → 老年逆袭/正能量
【节日喜庆】锣鼓+民乐 → 春节/中秋
【治愈白噪音】雨声+钢琴 → 失眠/养生
【保定老调】河北梆子片段 → 本地文化
【怀旧金曲】80年代流行歌曲变奏 → 青春回忆
【悬疑紧张】低音弦乐+心跳声 → 反诈科普
【温馨民谣】吉他+口琴 → 祖孙日常
【史诗交响】弦乐+铜管 → 人生回顾/大场面
```

**轮换规则**：每周提示词包自带BGM推荐，不再临时想。

### 创新维度5：平台差异化分镜（3套模板）

| 平台 | 分镜节奏 | 时长 | 特殊要求 |
|------|---------|------|---------|
| 抖音 | 快-快-快（每2秒一个变化） | 15-30秒 | 前3秒必须有视觉冲击 |
| 快手 | 中-快-中（留气口） | 20-45秒 | 方言配音加分 |
| 视频号 | 慢-中-慢（情感递进） | 30-60秒 | 家族群传播，结尾留转发钩子 |

**来源**：多模态带货手册的"平台大盘"+"视频指标"章节。

## 四、定时任务 v2.0 修正版

### 每周执行流程（新增"创新轮换"层）

```
周一 09:00 自动执行
    ↓
Step 1 市场扫描（不变）→ 判断当期情绪
    ↓
Step 2 选择叙事语法（新增）→ 从6种中选1种（按档期匹配）
    ↓
Step 3 选择场景组合（新增）→ 从8场景中选2个主推
    ↓
Step 4 选择钩子类型（新增）→ 从6类中选1个主钩子
    ↓
Step 5 匹配素材库（不变）→ 从人物底图/参考图中选锚点
    ↓
Step 6 套用模板生成（升级）→ 按选定叙事语法+场景+钩子生成提示词
    ↓
Step 7 合规检查（不变）→ T0-T4+禁用词
    ↓
Step 8 输出（不变）→ 腾讯文档+IMA备份+钉钉通知
```

### 产出物升级

**之前**：5套提示词（固定结构）  
**现在**：5套提示词（按周轮换结构）+ 1份"本周创新配置单"

**新增"创新配置单"格式**：
```
# 2026年第XX周 · 创新配置单

叙事语法：IP短片（微缩世界冒险）
场景组合：S1老院日常 + S4节日团圆
钩子类型：乡愁钩子
BGM推荐：国风温情（古筝+笛子）
平台适配：视频号慢节奏 + 抖音快节奏双版本

参考模板来源：
- 分镜结构：豆包IP短片模板（PaYVxKFhGaqP）
- 运镜库：视频工程规范（PXLzbyUoBURV）
- 文案风格：白沟箱包顾问腔（PgUNfBUSaVaX）
```

## 五、模板库调用机制（防闭门造车）

### 6份模板的分工

| 模板文件 | 固定使用 | 创新使用 |
|---------|---------|---------|
| 文生视频模板（竹林剑舞/Q版古风/十二星座） | 逐秒分镜格式（00:00-00:03） | 场景替换（竹林→老院）、角色替换（古风美人→保定老人） |
| 多模态带货手册 | 数据门槛（CES评分/完播率）、算法新规 | 9类模板骨架迁移到银发、组件工作台排列组合 |
| 酸奶店产品摄影 | 负面提示词清单、禁用词自检流程 | 产品图公式→人物图公式（替换[产品]为[老人]） |
| 白沟箱包工具箱 | 出图核心公式、英文锚词强制、质检门6件套 | 8场景模板库→银发8场景、顾问腔话术 |
| 豆包生视频模板 | 6种视频类型的完整分镜结构 | 每周轮换叙事语法、时间轴分镜格式 |
| 视频工程规范 | 7大工程要素（一致性/时间轴/运镜/转场/节奏/画质/中英混写） | 18运镜动词库、10种转场手法库 |

### 调用规则

```
每周产出时，必须标注：
- "本套提示词的分镜结构来自：豆包IP短片模板"
- "本套提示词的场景来自：白沟箱包工具箱S1场景"
- "本套提示词的运镜来自：视频工程规范18动词库"

目的：
1. 确保创新有据可查（不是凭空编造）
2. 后续迭代时知道哪些模板效果好/不好
3. 形成"模板效果档案"，指导长期优化
```

## 六、个人IP特色锚点（防止同质化）

### 你的3个不可替代标签

| 标签 | 内容 | 怎么固化到模板 |
|------|------|---------------|
| **保定大白话** | "整明白""弄利索""咱爸咱妈" | 每条配音文案必须含≥1个保定方言词 |
| **坑雷达** | "谁做谁知道""整半天白整了" | 每条反诈/科普内容必须含≥1个踩坑警示 |
| **45分钟红线** | 不劝人拼命，劝人省劲儿 | 每条内容结尾必须有"别太折腾"类兜底 |

### 特色检验清单（每条产出必查）

```
□ 含保定地理锚（白沟/保定/河北）
□ 含保定方言词（整/弄/咱/呵）
□ 不含 sellers腔（源头工厂价/赶紧下单）
□ 含顾问腔句式（值不值得入手，看你怎么判断）
□ 结尾有行动指令（下一步干什么）
□ 结尾有"别太折腾"类情绪兜底
```
