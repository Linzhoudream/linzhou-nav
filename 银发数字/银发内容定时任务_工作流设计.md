## 二、定时任务工作流设计

### 任务名称：银发爆款提示词周报（Silver Prompt Weekly）

### 核心逻辑

```
每周一 09:00 自动执行
    ↓
[输入层] 读取3个数据源
    ├── 腾讯文档：银发文件夹最新文件（扫描新增/修改）
    ├── 腾讯文档：共用素材库（他人模板+原始素材）
    └── 网络搜索：银发赛道最新爆款（抖音/快手/小红书）
    ↓
[处理层] AI分析与生成
    ├── 趋势提取：本周银发爆款Top3话题
    ├── 对标分析：爆款账号的内容结构拆解
    ├── 素材匹配：从原始素材中找可复用元素
    ├── 提示词生成：基于V2.0双轨模型生成新提示词
    └── 合规审查：T0-T4分级 + 广告法检查
    ↓
[输出层] 产物写入
    ├── 腾讯文档：新增"本周爆款提示词包"文件
    ├── 腾讯文档：更新"银发工作区_智能索引"
    └── IMA知识库：备份提示词包
    ↓
[通知层] 推送提醒
    └── 钉钉/微信："本周银发提示词已生成，请查收"
```

---

### 输入层详细设计

#### 输入1：腾讯文档银发文件夹（只读扫描）

**操作**：`manage.folder_list` 扫描银发文件夹，获取最近7天内修改的文件
**提取内容**：
- 新增/修改的文件列表
- 文件标题关键词（用于判断内容方向变化）
- 版本状态（如"V2.0最终双轨版"→判断是否已更新）

**频率**：每次执行时扫描
**算力**：1次API调用，约2秒

#### 输入2：共用素材库（定期索引）

**操作**：扫描"图片原始素材"和"他人模板"文件夹
**提取内容**：
- 原始素材：图片数量、文件名特征（推测内容主题）
- 他人模板：模板类型（文生视频/带货/豆包/工程规范）
- 新增素材：与上次扫描对比，发现新增内容

**频率**：每次执行时扫描
**算力**：2次API调用，约4秒

#### 输入3：网络搜索（银发爆款趋势）

**搜索策略**：
```
Query 1: "2026 银发短视频 爆款 抖音 老年内容 热门"
Query 2: "银发赛道 微短剧 中老年 付费 趋势 2026"
Query 3: "老年短视频 爆款文案 模板 2026"
Query 4: "快手 银发内容 热门账号 数据"
```

**提取内容**：
- 本周热门话题（如"养生""防骗""家庭关系"）
- 爆款内容结构（钩子+痛点+解决方案+CTA）
- 新兴内容形式（如"银发微短剧""AI数字人"）
- 平台政策变化（如AIGC标识新规）

**频率**：每次执行时搜索
**算力**：4次搜索，约30-60秒

---

### 处理层详细设计

#### 步骤1：趋势分析（AI执行）

**输入**：网络搜索结果 + 历史提示词库
**处理**：
1. 提取本周银发赛道Top3热门话题
2. 对比上周，判断话题持续性 or 新热点
3. 标记"高潜力话题"（搜索量↑ + 竞争度↓）

**输出**：趋势简报（3句话）
**算力**：AI推理，约30秒

#### 步骤2：爆款拆解（AI执行）

**输入**：网络搜索中的爆款案例
**处理**：
1. 拆解爆款视频结构：
   - 开头3秒钩子（什么吸引了点击？）
   - 中间内容（痛点/故事/知识）
   - 结尾CTA（关注/点赞/评论引导）
2. 提取可复用的"爆款元素"：
   - 文案模板（如"XX岁的我，终于明白了XX"）
   - 画面结构（如"老人+手机+惊讶表情"）
   - 音乐/音效类型

**输出**：爆款拆解报告（5-8个案例）
**算力**：AI推理，约60秒

#### 步骤3：素材匹配（AI执行）

**输入**：腾讯文档原始素材 + 爆款拆解结果
**处理**：
1. 将爆款元素与现有素材匹配：
   - "老人惊讶表情"→是否有类似原始素材？
   - "手机操作画面"→原始素材中是否有？
2. 标记"可复用素材"和"需补充素材"
3. 生成"素材采购建议"（如需补充，提示用户）

**输出**：素材匹配表
**算力**：AI推理，约30秒

#### 步骤4：提示词生成（AI执行）

**输入**：趋势分析 + 爆款拆解 + 素材匹配 + 银发V2.0方法论
**处理**：
1. 基于V2.0双轨模型生成提示词：
   - **TrackA（真实记录轨）**：基于原始素材的真实感提示词
   - **TrackB（AI创意轨）**：基于爆款拆解的创新提示词
2. 每条提示词包含：
   - 内容主题（如"防手机诈骗"）
   - 画面描述（详细到景别/动作/表情）
   - 文案脚本（15字以内钩子）
   - 合规检查（禁用词/标识要求）
   - T0-T4分级（建议使用等级）
   - 预期效果（参考爆款数据）

**输出**：本周提示词包（10-15条图片+视频提示词）
**算力**：AI推理，约120秒

#### 步骤5：合规审查（自动检查）

**输入**：生成的提示词
**检查项**：
1. 禁用词检查（广告法极限词/医疗宣称/诈骗暗示）
2. AIGC标识检查（是否需标注"AI生成"）
3. 肖像权检查（是否涉及真实老人形象）
4. T0-T4分级确认（确保分级合理）

**输出**：合规报告（通过/需修改项）
**算力**：关键词匹配，约10秒

## 四、定时任务配置（可直接使用）

### Cron表达式

```
0 9 * * 1
```

**含义**：每周一上午9:00执行

### 任务脚本框架

```javascript
// 银发爆款提示词周报 · 定时任务
// 频率：每周一 09:00
// 算力预估：6-8分钟

async function silverPromptWeekly() {
  // 1. 输入层
  const silverFiles = await tencentDocs.folderList('银发文件夹ID');
  const sharedAssets = await tencentDocs.folderList('共用素材库ID');
  const trends = await webSearch([
    '2026 银发短视频 爆款',
    '银发赛道 微短剧 中老年 趋势',
    '老年短视频 爆款文案 模板'
  ]);
  
  // 2. 处理层
  const trendReport = await aiAnalyze(trends);
  const viralCases = await aiDeconstruct(trends);
  const assetMap = await aiMatch(viralCases, sharedAssets);
  const prompts = await aiGenerate(trendReport, viralCases, assetMap);
  const compliance = await autoCheck(prompts);
  
  // 3. 输出层
  const docId = await tencentDocs.create(
    `银发提示词包_${getWeekNumber()}_${trendReport.topics[0]}`
  );
  await tencentDocs.write(docId, formatPrompts(prompts));
  await tencentDocs.updateIndex('银发工作区_智能索引', docId);
  await imaKnowledgeBase.backup(docId, prompts);
  
  // 4. 通知
  await dingTalk.notify(formatNotification(prompts, compliance));
}
```

## 六、风险与应对

### 风险1：腾讯文档API不稳定

**表现**：扫描失败、写入超时
**应对**：
- 失败时自动重试1次
- 连续2次失败则仅做网络搜索+生成提示词，暂存本地
- 下次执行时优先补写上次未完成的输出

### 风险2：网络搜索无新热点

**表现**：搜索结果与上周重复
**应对**：
- 对比上周趋势，判断是否为"持续性热点"
- 如果是老热点，生成"深度版"提示词（更细分场景）
- 如果是新热点，标记"紧急推荐"

### 风险3：算力耗尽

**表现**：任务执行到一半积分用完
**应对**：
- 任务设计为"可中断可恢复"：每个步骤完成后写状态标记
- 中断后下次执行时从断点恢复
- 算力紧张时自动降级：仅做趋势分析+生成3条核心提示词

### 风险4：用户未使用生成的提示词

**表现**：每周生成但用户从未打开
**应对**：
- 钉钉通知中加入"本周高潜力TOP3"，降低决策成本
- 每月生成"使用报告"：你生成了X条，使用了Y条，浪费了Z条
- 根据使用数据调整生成策略（多生成用户喜欢的类型）

## 七、用户手动操作流程（备用）

如果定时任务因算力/API问题无法执行，用户可手动完成：

**Step 1（5分钟）：看趋势**
- 打开抖音/快手，搜索"老人""养生""防骗"，看本周热门
- 记录3个最火的话题

**Step 2（5分钟）：拆爆款**
- 选1个爆款视频，拆解：
  - 开头3秒说了什么？
  - 中间讲了什么故事/知识？
  - 结尾怎么引导互动？

**Step 3（5分钟）：配素材**
- 打开腾讯文档"图片原始素材"文件夹
- 看有没有匹配的画面
- 没有的话，用手机拍一张（15秒）

**Step 4（5分钟）：写提示词**
- 用银发V2.0模板，填空：
  - 主题：[话题]
  - 画面：[景别]+[主体]+[动作]+[表情]
  - 文案：[15字以内钩子]
  - 合规：[禁用词检查]

**Step 5（5分钟）：生成**
- 复制提示词到baidu-image-gen或baidu-video-gen
- 生成后检查，T3以上需要人审

**总计：25分钟，5条提示词。**

## 八、验证与迭代

### 验证指标

| 指标 | 目标 | 验证方式 |
|------|------|---------|
| 提示词使用率 | >50%（每周10条中至少用5条） | 用户反馈/IMA使用记录 |
| 爆款率 | >10%（使用的提示词中10%成为爆款） | 抖音/快手后台数据 |
| 算力消耗 | <10分钟/周 | 任务执行日志 |
| 用户满意度 | >4分/5分 | 每周钉钉反馈 |

### 迭代机制

**每月回顾**：
1. 统计上月生成提示词的使用率
