## 一、全流程一页图

```
Phase 1 情报采集（早8:00 自动）
  ├─ 每日热点简报
  └─ 竞品动态监测
        ↓
Phase 2 人工补数据（早8:30 手动，30分钟）
  ├─ 付费平台截图（蝉妈/飞瓜等，可选）
  └─ 本店近7天数据导出
        ↓
Phase 3 创意生产（9:30起 半自动）
  ├─ 选题推荐（9:30）
  ├─ 脚本生成（10:00）
  ├─ 脚本审核（10:30，AI校验+人工确认）
  └─ 视频生成+后期（11:00起）
        ↓
Phase 4 多平台分发（14:00 自动）
  └─ 小红书/抖音/视频号/TikTok 文案适配
        ↓
Phase 5 周度复盘（每周一 9:00）
  └─ 数据复盘+优化建议
```

**核心逻辑：AI干"从0到60分"的活，你干"从60到80分"的活（选品/判断/拍板）。**

## 三、AI拿不到数据时的降级策略

| 场景 | 降级方案 |
|------|---------|
| 蝉妈/飞瓜不可用 | 抖音热榜+知乎+1688公开数据，标「⚠️数据降级」 |
| TikTok数据不可用 | TikTok公开搜索+谷歌趋势 |
| 小红书评论区抓不到 | 笔记正文+知乎 |
| 人工没补任何数据 | 基于公开情报生成，标「⚠️建议补充」 |

**原则：缺数据≠停摆，先出内容，能补再补。**
