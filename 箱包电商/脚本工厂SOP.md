模块B · 短视频脚本工厂 SOP（原 T4 内容生产改造版）
作用：基于模块A 选题库，产出抖音版 + TikTok版（+小红书版）原生短视频脚本，含分镜/口播/青色高亮词/CTA/视觉提示词。 与原 T4 的区别：①新增 TikTok 英文版；②视角从”产业顾问引流”→”箱包卖家/品牌 获客带货”；③CTA 从”关注/私信咨询”→”下单/购物车/主页链接”（按参数表目标切换）；④保定方言→客户语言(中文/英文)。
核心公式（沿用原 T4）
痛点 → 心法 → 金句 → 三步法 + 表格脚本（时间 / 画面 / 台词 / 镜头）

口播脚本（分镜时间+画面+台词），按参数表人设（老板出镜/工厂实拍/旁白）

C. 小红书版（图文笔记，可选）【种草向】
产出 日期-小红书版.md：深底青字封面 / 标题带关键词 / 正文500字+ / AI生成标注 / 收藏+关注CTA / 午12发。正文全重写非搬运。
D. 视觉提示词（供客户 AI 出图，本技能不自动生成）
每个平台末尾附英文 image-gen 提示词：
抖音帧：vertical 9:16 short-video frame, dark navy background, white text with cyan highlight, factory owner, mobile UI
TikTok帧：vertical 9:16 TikTok frame, bright clean background, bold English text overlay, bag product hero shot, trendy

E. 指纹差异说明（防跨平台限流）
双/三版本各自注明与对方在画面/音频/文本/发布时间上的不同。例：抖音用保定/中文旁白、TikTok 用英文无旁白快剪、小红书静态图文——三者素材不共用，满足平台去重。
边界
只起草不自动发布（除非参数表开启）；不经营粉丝、不实时答疑、不收费、不自动出图（只给提示词）。发布由客户审核后执行。
