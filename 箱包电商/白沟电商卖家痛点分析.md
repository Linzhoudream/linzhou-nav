## 二、按人群拆解：4类卖家的真实困境

### A. 工厂型卖家（有产能，没品牌）— 最痛

1. **同质化内卷**：贴牌加工为主，缺乏自主品牌和设计，靠低价竞争。"2000多个款式，别人同款一出，自己的就卖不动了"——喜玛诺张文君（央广网2026-07）
2. **原创被抄，维权难**：外观设计专利授权原来要4-6个月，等批下来仿品已铺满市场。快维中心2025年底成立后压缩到10个工作日，但多数小厂不知道（保定市政府2026-07）
3. **设计成本高**：请设计师月薪6000+，白沟作为城镇留不住人。AI设计平台已落地但多数工厂不会用（爱企查产业分析）
4. **滞销率高**：凭经验做货，爆款率低。阳齐箱包用AI设计前滞销率30%，用后降到接近0——但多数工厂还在靠经验赌（信号雷达2026-07-17/20）

### B. 贸易型卖家（网供/档口，赚差价）— 利润见底

1. **价格战白热化**：大量网供商涌入导致市场饱和，利润压缩到极低水平，甚至"赔钱卖货"。中间商退场，旧渠道失效（爱企查产业分析2026）
2. **流量成本涨**：线上获客成本逐年攀升，"网供一条街"线下批发也在萎缩。传统等客上门模式失效（多源交叉验证）
3. **品质参差不齐**：低价工厂用回收板材冒充全新PC、登机箱尺寸虚标被扣货、配件偷工减料。采购方信任度低（博客园2026采购指南）
4. **高仿灰色地带**：高仿名牌包仍是白沟灰色分支，2026年监管趋严后转入私域隐秘运营。正规卖家被拖累声誉（微博2026渠道追踪）

### C. 个人/小卖家（一个人干，资源有限）— 最迷茫

1. **铺货=零单**：1688一键铺货，和上万人用同图同描述同价。3个月零单是常态（林舟亲身经历）
2. **视觉制作搞不起**：请摄影师拍一组图300元起，做详情页500-800元，单款视觉成本超1500元，利润才200-300元（搜狐1688调研2026）
3. **AI工具试了放弃**：97.4%听说过AI→53.2%试过→只有33%持续用。58.5%因价格放弃续费（赛迪智库+网商银行2026）
4. **选品全靠赌**：不懂平台规则硬发=闭眼打靶。大品类不是大市场是大红海（林舟亲身经历）

### D. 跨境卖家（想出海，不懂规则）— 有机会但坑多

1. **侵权一击致死**：选品没想过版权问题，被投诉侵权直接封店（林舟亲身经历：敦煌网出两单即被关）
2. **合规门槛攀升**：欧美对环保材质、TSA海关锁认证、航空尺寸标准核查收紧（博客园2026采购指南）
3. **翻译/美工/运营缺人**："翻译、美工、运营、客服缺一不可，小企业根本扛不住人力成本"——白沟跨境创业者张旺（中国皮革协会2026）
4. **Temu比价压利润**：Temu全网比价逻辑，贵0.5美元就下架。利润率压到不到10%（林舟亲身经历）

## 四、AI鸿沟

- 97.4%听说过AI → 53.2%试过 → 只有33%持续使用，每一层流失近半
- 58.5%因价格放弃续费
- 大企业50%+已将AI融入完整工作流，小微企业仅5.1%，十倍之差
- 白沟AI共享设计平台已落地（阳齐近百款、滞销率30%→0），"宝贸通"数字贸易平台上线，6个AI OPC友好场景发布——但多数中小卖家"知道有但不会用"
- **核心鸿沟不是技术，是翻译**：工具在那儿，数据在那儿，政策在那儿。缺的是一个人把"AI能做什么"翻译成"你的具体问题怎么解决"

## 六、核心结论

1. 白沟电商卖家的痛点分两类："AI能解但没人教"和"AI解不了的行业结构问题"。林舟的位置在中间，做翻译官。
2. 最大的机会不是卖AI工具，是帮卖家把已有的AI工具用起来。工具在平台上放着、政策在政府那儿放着、数据在报告里放着——缺的是一个人把这些翻译成"你的具体问题怎么解决"。
3. 第一个demo建议：找一个白沟老板，帮他用AI设计平台做1款包的设计，用前后对比证明价值。
