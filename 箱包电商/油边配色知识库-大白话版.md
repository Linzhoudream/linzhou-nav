二、颜色是咋调出来的（基础配色规则）

核心就记住三点，跟画画调颜料一个理儿：

1. 三原色混色（红、黄、蓝是祖宗）：
   * 红 + 黄 = 橙（差不多量是正橙，红多就偏红橙，黄多就偏黄橙）。
   * 红 + 蓝 = 紫。
   * 黄 + 蓝 = 绿。
   * 红+黄+蓝全混一起 ≈ 深棕色/差不多算黑色了。
2. 想让颜色变浅或变深：
   * 加白 → 颜色变浅、变粉嫩。
   * 加黑 → 颜色变深、变暗。
   * 三原色混出灰色后，再加白，就能得到各种浅灰色。
3. 调边油要特别注意的：
   * 红色、蓝色特别“上色”，劲儿大，加的时候要一点一点来，别手一抖倒多了。
   * 黄色、白色相对“不上色”，劲儿小，可以稍微多加点。
   * 最重要：每次调成功一个色，一定拿本子把比例记下来！下次照着调，省时省料。

四、标准的干活步骤（工艺SOP）

一套完整的油边流程，差不多15分钟内搞定一轮：

1. 准备（5分钟）：把皮边擦干净，有毛刺的稍微打磨一下。
2. 打底（一次就行）：薄薄涂一层打底剂（比如AR6301），把细小裂缝填上，晾干。
3. 打磨：等打底剂干透，用细砂纸轻轻磨平。
4. 上面油（关键，2-3遍）：
   * 把调好的面油，薄薄地、均匀地涂上去。
   * 一定要等这一遍完全干透，再涂下一遍。
   * 如果用那种速干可烫的边油（如FENICE），最后一遍涂完可以用烙铁小心烫一下，更亮更韧。
5. 检查收尾：看看颜色匀不匀、亮不亮，有瑕疵的地方小补一下。

五、常见问题咋解决（故障诊断）

出啥问题了 大概率因为啥 该咋整
边油脱落 底下那层没干透就急着涂上面；或者皮边有油没擦净。 返工，擦干净，确保每一层都彻底干透再涂下一层。
边油开裂 油涂太厚了，外面干里面不干；或者皮子折弯的地方没做软。 记住秘诀：薄涂，多涂两三次。 拐弯的地方涂完用手活动一下再晾干。
起泡 刷太快把空气裹进去了；或者底层还没干。 慢点、均匀地刷。耐心等每层干透。
颜色不均 颜料没调匀；或者搅拌不充分。 严格按记好的比例调，并且充分搅匀了再用。
光泽不够 没做最后的烫边处理；或者边油本身就不够亮。 换用可烫型的亮光边油，最后一步烫一下。

这个知识库就是给智能体准备的“大脑”，告诉它：

1. 用啥工具（材料）。
2. 颜色咋变出来（规则）。
3. 有现成方子可以参考但得验证（案例）。
4. 活儿按啥步骤干（流程）。
5. 出了问题咋办（诊断）。
