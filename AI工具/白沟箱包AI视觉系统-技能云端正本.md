核心工作流水线（固定4步执行 + 第5步闸门）
Step1 多模态信息自动提取
图片输入：识别包型、材质、主色、五金款式、版型比例、结构细节
文字输入：提取箱包类型/材质/尺寸/人群/风格/卖点

Step3 分场景生成专属中文提示词

Step4 合规终审校验
自动匹配抖音/淘宝/小红书/亚马逊2026审核规则，输出自检清单；标注极限词、水印、AI生成声明、图片尺寸规范。
Step5 出图闸门与生图审核（定时任务”自动出图”模式）
适用：每日定时任务 5017165（平台主线）或 cron 11:00 步，从旧规则”只出 prompt 绝不自动出图”升级为”自动出前 N 代表图 + 人工闸门”。目的：用户只给提示词时缺乏直观感受，难以判断是否值得做全套；改出少量代表图，让用户一眼定夺。
输入池：Step2/Step3 产出的款式提示词池。当前每日口径约 14 个款式（稳定线 A1–A8 + 创新线 B1–B6，已带爆款潜力优先级排序）。
自动初审（pre-filter，不进代表图）：每张候选图套出图质检门（产品 hero / 深蓝调色 / 无烤字水印 / 9:16）+ 四平台合规清单；任一不达标即打回重出或丢弃，不占用代表图名额。
出图闸门（只出代表图，不出全套）：仅调用图像 API 自动渲染第一梯队前 3–4 名（如 A3 包挂同源、A1 托特、A2 猫包、A8 封面），每款 1 张代表图（首图/主视觉），不展开全套 5 张。单日闸门代表图封顶 4 张。
人工终审闸门（go/no-go）：把代表图 + 各自爆款潜力评分 + 预估返工点呈现给用户，明确问”哪些值得做全套套图？”；用户选定款 → 再对通过款展开全套 5 张（Step2 分镜）；未通过款当次丢弃，不再消耗 credits。
成本闸门：单日自动出图总量 = 闸门代表图（≤4 张）+ 通过款全套（每款 ≤5 张），总张数封顶，杜绝无脑全出。
降级兜底：若沙箱当前无可用图像 API（headless 渲染不可用），闸门退化为”出前 3–4 款高清渲染 prompt + 一键出图按钮”，等人工在即梦/seedance 一键执行，仍保留”先看代表再决定是否全套”的判断节奏。
