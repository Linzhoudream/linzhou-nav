## 🌱 新手入门级（Day 1-2）

**目标**：学会跟AI正常对话，完成基础任务

### 模板1：万能角色扮演法

**适用场景**：让AI变成任何领域的专家帮你干活

```
你现在是【填入职业，如：资深文案策划/程序员/营销专家】。
你的任务是【填入具体任务】。
要求：
1. 【要求1，如：用通俗易懂的语言】
2. 【要求2，如：给出具体步骤】
3. 【要求3，如：提供案例说明】
```

**案例**：
```
你现在是资深短视频脚本策划。
你的任务是为一位美食博主写3个抖音短视频脚本，主题是"5分钟早餐"。
要求：
1. 每个脚本控制在30秒内
2. 开头要有钩子（吸引人看下去）
3. 给出具体的拍摄建议
```

**变现方式**：
- 帮商家写短视频脚本，每条50-200元
- 在闲鱼/淘宝接单"AI代写脚本"

---

### 模板2：分步执行法

**适用场景**：复杂任务拆解成小步骤

```
请一步步帮我完成以下任务：
【填入你的任务】

每一步都要：
1. 说明这一步要做什么
2. 给出具体操作
3. 告诉我为什么要这样做
```

**案例**：
```
请一步步帮我完成以下任务：
我想在小红书上卖自制手工艺品

每一步都要：
1. 说明这一步要做什么
2. 给出具体操作
3. 告诉我为什么要这样做
```

**变现方式**：
- 用这个方法帮别人做"小红书开店咨询"
- 收费标准：200-500元/次

---

### 模板3：示例学习法（Few-shot）

**适用场景**：让AI模仿你给的例子

```
我会给你几个例子，请你学习它们的风格和规律，然后按照同样的风格完成新任务。

例子1：【给出例子】
例子2：【给出例子】

现在请处理：【新任务】
```

**案例**：
```
我会给你几个例子，请你学习它们的风格和规律，然后按照同样的风格完成新任务。

例子1：
标题：这款面霜让我熬大夜也不暗沉✨
正文：姐妹们！最近加班到崩溃...（略）

例子2：
标题：黄皮亲妈！这个精华真的会发光🌟
正文：说实话一开始不信...（略）

现在请处理：
为一款"减肥茶"写3篇小红书种草笔记
```

**变现方式**：
- 批量生产小红书/抖音文案
- 接品牌方的"种草文案"订单，每篇30-100元

## 🚀 进阶级（Day 3-5）

**目标**：学会优化提示词，让AI输出更精准

### 模板4：结构化输出法

**适用场景**：需要AI给出规范格式的内容

```
请按照以下结构完成【任务】：

一、背景分析
（要求：...）

二、解决方案
（要求：...）

三、具体步骤
1. 
2. 
3. 

四、注意事项
- 
- 

五、预期效果
```

**案例**：
```
请按照以下结构完成"如何在一个月内涨粉1万"的小红书运营方案：

一、账号定位分析
（要求：明确目标人群和内容方向）

二、内容策略
（要求：给出3个内容栏目规划）

三、具体执行计划
1. 第1周：...
2. 第2周：...
（略）

四、常见坑点
- 
- 

五、预期效果和数据指标
```

**变现方式**：
- 出售"行业方案模板"（如：餐饮店抖音运营方案）
- 在知识星球/社群里分享，收取会员费

---

### 模板5：批判改进法

**适用场景**：让AI帮你优化已有的内容

```
这是我写的【内容类型】：
---
【粘贴你的内容】
---

请从以下角度 critique（批判）它：
1. 逻辑是否清晰？
2. 有没有遗漏关键点？
3. 表达是否吸引人？

然后给出改进版本。
```

**案例**：
```
这是我写的产品详情页文案：
---
本产品采用先进技术，质量可靠，价格实惠，欢迎购买。
---

请从以下角度 critique（批判）它：
1. 逻辑是否清晰？
2. 有没有遗漏关键点？
3. 表达是否吸引人？

然后给出改进版本。
```

**变现方式**：
- 提供"AI优化服务"，帮别人改文案/改方案
- 收费标准：根据字数/复杂度定价

---

### 模板6：多角色辩论法

**适用场景**：需要多角度分析问题

```
请从以下3个角色的角度，分别分析【问题】：

角色1：【如：资深从业者】
观点：
理由：

角色2：【如：新手用户】
观点：
理由：

角色3：【如：行业观察者】
观点：
理由：

最后给出综合建议。
```

**案例**：
```
请从以下3个角色的角度，分别分析"实体店要不要做抖音"：

角色1：餐饮店老板（已做抖音，月入10万+）
观点：
理由：

角色2：传统零售店主（观望中）
观点：
理由：

角色3：抖音本地生活运营专家
观点：
理由：

最后给出综合建议。
```

**变现方式**：
- 制作"行业分析报告"
- 卖给相关从业者/商家

## 💎 专家级（Day 6-7）

**目标**：结合工作流/智能体，实现自动化变现

### 模板7：工作流设计法

**适用场景**：把重复任务交给AI自动完成

```
我想设计一个AI工作流来自动完成【任务】。

请帮我设计：
1. 需要哪些步骤？
2. 每个步骤需要什么提示词？
3. 如何串联这些步骤？
4. 需要什么工具配合？（如：API、自动化软件）

最终输出：完整的工作流说明书
```

**案例**：
```
我想设计一个AI工作流来自动完成"每日热点资讯推送"。

请帮我设计：
1. 需要哪些步骤？
2. 每个步骤需要什么提示词？
3. 如何串联这些步骤？
4. 需要什么工具配合？

最终输出：完整的工作流说明书
```

**变现方式**：
- 出售"自动化工作流方案"
- 帮企业搭建AI工作流，收费5000-20000元/套

## 💼 按职业分类模板

### 1️⃣ 文案/营销人员

**模板A：爆款标题生成器**
```
请为【产品/内容】生成20个吸引人的标题。
要求：
- 包含数字型（如：3个技巧...）
- 包含疑问型（如：你知道吗？）
- 包含痛点型（如：告别...）
- 包含好奇型（如：竟然可以...）
目标平台：【小红书/抖音/公众号等】
```

**变现方式**：
- 批量生成标题出售给自媒体
- 接"标题优化"外包单

---

**模板B：朋友圈营销文案**
```
请为【产品】写7条朋友圈营销文案，覆盖一周。
要求：
- 周一：种草型
- 周二：痛点型
- 周三：案例型
- 周四：互动型
- 周五：促销型
- 周六：生活型
- 周日：总结型
每条控制在150字以内，要自然不生硬。
```

**变现方式**：
- 帮微商/代购写朋友圈文案
- 收费标准：200-500元/月

---

### 2️⃣ 程序员/技术人员

**模板C：代码解释器**
```
请解释以下代码的功能和逻辑：

【粘贴代码】
---

要求：
1. 用大白话说明这段代码做什么
2. 指出关键逻辑部分
3. 如果有bug，请指出并给出修复方案
```

**变现方式**：
- 提供"代码审查服务"

**模板D：自动化脚本生成器**

```
请帮我写一个【编程语言】脚本，实现以下功能：

要求：

3. 说明可能的问题和解决方案
```

**变现方式**：

## 💰 变现路径指南

## 📌 使用建议

1. **从模板1-3开始**，先掌握基础对话
2. **每天练习一个模板**，照着案例改
3. **先给自己用**，再考虑给别人用
4. **记录效果**，不断优化提示词
5. **组合使用模板**，解决复杂问题
