# 实体店 AI 内容代运营工作流方法论

> **脱敏说明**：本文档从一个本地餐饮店 AI 内容生产项目中提炼而成。所有 `[占位符]` 处请替换为你的实际信息。方法论内容保持原样，不做修饰。

日期：2026-08-30

---

## 核心原则：老板不读文件，老板做动作

这是整个代运营工作流最重要的一个判断：

> 优先级分的是"动作"，不是"文件"。
> 什么时候让他做什么动作，比"哪个文件先给"重要得多。

推到极致的结论：**日常给 0 个文件。每天一条微信消息 + 一张图就够了。文件夹里放的是"存档"，不是"教材"。**

类比：给司机导航，不给发动机图纸。

## 一、人机分工边界

| 角色 | 做什么 | 不做什么 |
| --- | --- | --- |
| AI | 背景氛围、光影特效、字幕配乐、文案分镜、动效包装、场景延伸 | 不生成食物本体、不生成门头图/环境图/后厨图 |
| 运营（你） | 每天筛1条AI产出、过质检、发给老板、回收数据、每周复盘 | 不把提示词/合规依据发给老板 |
| 老板 | 拍3张产品照、拍3条门头实拍、每天选1条发出去 | 不读文件、不改提示词、不研究AI技术 |

核心原则：**AI 只做包装优化，不生成食物本体，所有产品必须基于实拍素材。**

## 二、知识库搭建（开工前必须完成）

### 10 大分类

| 分类 | 内容 | 是否可AI创意 |
| --- | --- | --- |
| 门店基础信息 | 店名、地址、营业时间、门头特征、产品线、实际杯型 | ❌ Lock字段 |
| 真实配料表 | 每款产品杯里有什么、禁止AI添加清单 | ❌ 防漂移基准 |
| 合规底线 | AI标识标准、广告法分级、平台规则、食品宣传雷区 | ❌ 硬规则 |
| 品牌人设 | 出镜人设、语调、差异化锚点 | ❌ 不可虚构 |
| 爆款公式库 | 公式A-E的选题模板 | ✅ 可扩展 |
| 平台合规细则 | 抖音/小红书/美团/视频号的标识和审核规则 | ❌ 须核实最新版 |
| 历史数据 | 爆款记录、顾客好评、迭代记录 | ✅ 持续更新 |
| 趋势与地域食材 | 行业趋势、`[本地食材库]`、季节限定逻辑 | ✅ 可扩展 |
| 转化组件 | POI定位、团购链接、承接话术、UGC激励机制 | ❌ 须真实 |
| 合规凭证 | 采购票据、检测报告、配料公示、肖像授权 | ❌ 须真实文件 |

### 开工前必填的 4 样

| 顺序 | 缺什么 | 为什么关键 |
| --- | --- | --- |
| 1 | 拍3张产品身份证照 | AI出图的唯一垫图来源，没有它=漂移 |
| 2 | 真实配料表 | 防漂移的唯一基准，AI不能加料也不能少画 |
| 3 | 精确门牌号+营业时间 | POI认领必备，导航到店的落点 |
| 4 | `[时令元素]`确认 | 确认有没有，决定第一条内容能不能直接发 |

> 这 4 样补完，第一条内容就能出。其余边做边补。

## 三、每周运行节奏（1+6 模式）

### 周一：60 分钟集中处理

| 角色 | 工作内容 | 耗时 |
| --- | --- | --- |
| 老板 | 拍摄本周实拍素材：产品制作过程、门店日常、出镜片段 | 30 分钟 |
| 运营 | 更新知识库 → AI批量生成7天内容方案 → 输出3套/天备选 | 20 分钟 |
| 老板 | 抽检方案、确认合规、选定本周发布排期 | 10 分钟 |

### 周二至周日：每日 5 分钟轻执行

| 角色 | 工作内容 | 耗时 |
| --- | --- | --- |
| 老板 | 从当日3套备选中选1套 → 一键发布 → 挂载POI和团购 | 5 分钟 |
| 运营 | 自动监测数据、回复评论标准话术、每周汇总更新知识库 | 后台自动 |

## 四、每日内容产出结构

AI 每天产出1条，运营过筛，筛中的发给老板。

### V2 产出块结构

| 块 | 给谁 | 内容 |
| --- | --- | --- |
| 头部标记 | 运营 | 状态/轨道/模板A-E/类型 |
| 【给老板】 | 老板 | ≤60字文案（带收藏引导）+ 今天拍什么 + 发布时间 + 4-5步操作 |
| 【给你】 | 运营 | 为什么选这条/前置依赖/图片提示词/I2V视频提示词/筛选要点5条/合规判断表/出图参数 |
| 【数据回收】 | 运营 | 发布后回填播放·收藏·到店 |

### 筛选标准：3 通用 + 2 专属

| 类型 | 检查项 | 不对就弃 |
| --- | --- | --- |
| 通用1 | 产品颜色跟实拍一致吗 | 变色 → 弃 |
| 通用2 | 杯里的料跟实拍一样多吗 | 凭空加料 → 弃（红线） |
| 通用3 | 有乱码字吗 | 有 → 弃 |
| 专属1 | 按本条场景定（如：有手部就查六指） | 错 → 弃 |
| 专属2 | 按本条场景定（如：时令食材有没有被画进杯里） | 进杯 → 弃 |

### 内容配比

| 类型 | 占比 |
| --- | --- |
| 制作食欲特写 | 40% |
| 老板日常 | 30% |
| 同城互动 | 20% |
| 团购转化 | 10% |

### 双轨架构

- **稳定线 60%**：已验证的套路，AI 批量变体
- **改良线 30%**：看数据微调
- **创新线 10%**：博黑马，允许翻车（单周翻车 ≥3 条就减半）

## 五、给老板的发放节奏（P0-P3）

### P0 · 本周开局：给1个文件 + 3个动作

把一个文件夹分享给老板，微信发一句：打开这个，做第一屏那3件事就行。

3 个动作：
1. 拍3张产品照（1分钟）
2. 拍3条门头实拍（10分钟）
3. 确认时令元素有没有（10秒）

> 不要解释为什么，不要补充背景，不要发第二份文件。

### P1 · 每天日常：给0个文件

每天一条微信，三样东西：
- 一张图
- 一段文案，可直接复制
- 今天10:30发（或16:30）

不分享任何新文件。他要问"这个图怎么来的"，再解释——他说不定根本不问。

### P2 · 第2-3周他上手了：按需单页给

触发条件：他主动问"为什么"。

| 他问什么 | 给他什么 |
| --- | --- |
| "为什么非得10:30发？" | 发布时间那一页 |
| "我能不能拍点别的？" | 内容比例那一页 |
| "这个能挂团购了吗？" | POI认领+团购挂载那一页 |
| "我这个文案能这么说吗？" | 用词四档分级（最实用） |

> ⚠️ 一次只给一页。不要"顺便把相关的都发你"。

### P3 · 他要学了才给

| 内容 | 什么时候给 |
| --- | --- |
| 提示词全文 | 他问"这个图怎么做出来的" |
| 合规依据（国标、广告法） | 他问"为什么非要标AI" |
| 质检6条 | 他开始自己筛图了 |

> 给了也只给一段，不给全文。

## 六、进阶与退步信号

| 信号 | 动作 |
| --- | --- |
| 连续一周都按时发了 | 可以加 P2 内容 |
| 主动问"为什么" | 可以加到 P2/P3 |
| 开始自己改文案 | 给用词四档分级（最能防出事） |
| 漏发了/拖了/说不做了 | **退回去，减内容，别加** |

> 最后一条是重点：进度掉了的正确反应是减负，不是加油打气、更不是发更多资料让他"重视起来"。

## 七、数据回收（最重要的一环）

### 每条发布后回填

| 日期 | 条号 | 播放 | 收藏 | 到店/核销 | 结论 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

### 看自己的数据，不看别人的爆款

> 看自己的数据比看别人的爆款准得多。
> 本地生活算法权重是 收藏率 > 核销率 > GMV > 复购率 > 完播率，
> 一条 5000 播放 50 收藏的，比 50 万播放 200 收藏的有用得多——后者 99% 的人不在你本地。

### 每周"看别人"（不是每天）

- 每周1次，10分钟：看同城同品类，不看全国爆款
- 每月1次：更新场景模板库，把验证过的选题固化
- 不追视觉奇观爆款——赛道不同，抄不了也不该抄

## 八、云端工作台分层架构

给老板搭的文档系统，核心逻辑是分层隔离：

| 层级 | 文件夹 | 老板看吗 | 内容 |
| --- | --- | --- | --- |
| 日常执行 | 01_每日每周执行SOP | ✅ 天天看 | 打卡清单、发视频流程、每周计划 |
| 运营素材 | 02_抖音运营素材库 | 偶尔翻 | 封面模板、脚本库、选题库、发布规范 |
| 私域运营 | 03_私域运营库 | 偶尔翻 | 话术、朋友圈文案、客户标签 |
| 经营数据 | 04_门店经营数据 | 偶尔翻 | 记账、库存、复盘表 |
| 合规风控 | 05_合规红线 | 不用看 | 禁用词、AI标注规范、自查表 |
| 进阶预案 | 06_进阶与未来升级 | 不用看 | 增值方案、脱加盟备用预案、AI使用手册 |

三条铁律：
1. **老板只看01执行文件夹**，复杂方案自动隐藏，不焦虑
2. **你后台更新，他打开自动最新**，不用重新接收
3. **微信点开收藏→点对应文件**，不用APP不用电脑

## 九、旧版复盘教训：为什么第一版没跑起来

### 旧版的6个问题

| # | 问题 | 后果 |
| --- | --- | --- |
| 1 | 标识写"AI辅助创作"而非"AI生成" | 不合规，白标 |
| 2 | 第一天让老板"删旧视频" | 删除比创作更需要判断力，他不知道删什么 |
| 3 | 没提3条门头实拍门槛 | 团购挂不上去，后面全白做 |
| 4 | 第2-3周表格是空的 | 不知道接下来干什么→"没反馈"的直接原因 |
| 5 | 禁词表一刀切 | 把"手工/鲜奶/低卡"也禁了，白白放弃好词 |
| 6 | 排30天计划 | 心理压力大，第一反应"算了没空" |

### 替代方案

> 不是他不想做，是文档没给他一个他愿意立刻做的动作。
> 把"删视频"换成"拍3张照片"，事就成了。

| 旧版做法 | 新版做法 |
| --- | --- |
| 给3页启动包 | 给1个文件夹，第一屏3件事 |
| 第一天删旧视频 | 第一天拍3张照片 |
| 排30天计划 | 当天15分钟做完 |
| 禁词表一刀切 | 四档分级（有依据就能说） |
| 标识"AI辅助创作" | 标识"AI生成" |
| 空表格留作业 | 每天一条微信给图给文案 |

---

## 一句话总结

> **给老板的东西，控制在"一屏看完+一个动作"。多了不是更负责，是更可能让他放弃。**
