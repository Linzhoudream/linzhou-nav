# 每日内容流水线（产出 → 筛选 → 发布）

> **脱敏说明**：本文档从一个本地餐饮店 AI 内容生产项目中脱敏而来。所有 `[占位符]` 处请替换为你的实际信息。方法论内容保持原样，不做修饰。

日期：2026-08-30

---

## 怎么用（三行说完）

1. AI 每天产出 1 条，追加到本文档末尾，标记「待筛选」
2. 你打开看【给你】那部分，判断要不要用，把状态改成「选用」或「弃用」
3. 选用的，只把【给老板】那一段发给老板——提示词、合规依据这些别发，他看着头疼

---

## 每天的产出结构

V2 结构（2026-08-30 起）：

| 块 | 给谁 | 内容 |
| --- | --- | --- |
| 头部标记 | 运营 | 状态 / 轨道 / 模板 A–E / 类型 |
| 【给老板】 | 老板 | ≤60 字文案（带收藏引导）+ 今天拍什么 + 发布时间 + 4–5 步操作。就这些，别多发 |
| 【给你】 | 运营 | 为什么选这条 / 前置依赖 / 图片提示词（主体锁定+中文场景+英文锚词+排除清单）/ I2V 视频提示词 / 筛选要点 5 条 / 合规判断表 / 出图参数 |
| 【数据回收】 | 运营 | 发布后回填播放·收藏·到店，攒够两周看结论 |

## 筛选要点

统一为「3 条通用 + 2 条本条专属」：

| 类型 | 检查项 | 不对就弃 |
| --- | --- | --- |
| 通用 1 | 产品颜色跟实拍一致吗 | 变色 → 弃 |
| 通用 2 | 杯里的料跟实拍一样多吗 | 凭空加料 → 弃（红线） |
| 通用 3 | 有乱码字吗 | 有 → 弃 |
| 专属 1 | 按本条场景定（如：有手部就查六指） | 错 → 弃 |
| 专属 2 | 按本条场景定（如：时令食材有没有被画进杯里） | 进杯 → 弃 |

### 筛选的三个快判断（不用全看）

| 看什么 | 不对就弃 |
| --- | --- |
| 产品颜色跟实拍一致吗 | 变色 → 弃 |
| 杯里的料有没有变多 | 凭空加了料 → 弃（这是红线，不是美观问题） |
| 画面里有没有乱码字 | 有 → 弃（AI 生成的中文基本都是乱码，文字一律剪辑工具后期加） |

### 状态标记

待筛选 → 选用 / 弃用 → 已发给老板 → 已发布

## 提示词规范 V2

> 核心原则：学前序项目的"发动机"风格，不学商业 AI 模板的"广告感"。
> 它们是 8K + 电影光 + 产品悬浮；我们是自然光 + 生活痕迹 + 产品不动。

### 1. 提示词必须是「中文描述 + 英文锚词」

前序项目实测：纯中文提示词抽卡率高，不合格。中文负责讲清楚要什么，英文锚词负责稳住模型。

**英文锚词段（每段提示词原样保留）：**

```
vertical 9:16 frame, realistic lifestyle photo, natural lighting,
product hero, shallow depth of field, soft natural contrast,
slight film grain, no text overlay, no watermark,
--ar 9:16 --style raw
```

小红书把 `--ar 9:16` 改成 `--ar 3:4`。

> ⚠️ 不要用 cinematic lighting / premium editorial / high contrast / 统一深色背景——那些是大牌广告参数，小店内容用了会"端着"，观众秒划走。

### 2. 图生视频用 I2V 公式

```
from this frame: [运镜], [动效], duration 5s, rhythm locked to [慢/中/快]
```

**运镜库（只保留这四个）：**

| 保留 | 说明 |
| --- | --- |
| slow handheld push-in | 缓慢手持推近，10% 的条用 |
| macro pull focus | 微距移焦，做配料特写 |
| static + light movement | 静止 + 光影微动，90% 的条用这个 |
| static + background blur movement | 静止 + 背景虚影移动 |

删掉的运镜（会导致产品漂移或显得假）：360° orbit、whip pan、crane up、FPV fly-through、产品悬浮、产品旋转。

### 3. 排除清单（提示词尾部原样保留）

```
不要文字、字母、招牌字样、水印
不要添加杯中不存在的配料、水果、谷物、酱料
不要擅自改变罐体/杯体颜色（须与垫图一致）、罐型、液体颜色
不要影楼打光、3D渲染感、过度磨皮、塑料质感
不要六根手指、扭曲的手部
不要产品悬浮、飞行、旋转
```

约束表述统一用这句（比"禁止凭空加料"更严密）：

> 禁止虚构或猜测无法确认的原料、成分和工艺。

### 4. 场景模板库（选题从这里轮换，避免重复）

| 模板 | 适用类型 | 场景 | 情绪词 |
| --- | --- | --- | --- |
| A 守店 | 老板日常 30% | 柜台一角，擦拭台面的手 | 踏实 |
| B 街坊 | 同城互动 20% | 老街巷口，车筐里的产品 | 熟 |
| C 时令 | 制作特写 40%（季节节点） | 桌面 + 当季本地食材（只在杯外） | 应季 |
| D 制作 | 制作特写 40% | 操作台，装杯动作 | 实在 |
| E 团购 | 团购转化 10% | 柜台正中 + 空白立牌 | 清楚 |

> ⚠️ C 模板的当季食材只能在杯外，绝不能进杯——凭空加料是红线。

### 5. 数据回收（这条最重要）

每条发布后，回到本文档把数据补上。攒够两周，就能看出哪类内容真的有效。

| 日期 | 条号 | 播放 | 收藏 | 到店/核销 | 结论 |
| --- | --- | --- | --- | --- | --- |
| ？ | ？ | ？ | ？ | ？ | ？ |

> **看自己的数据比看别人的爆款准得多。**
> 本地生活的算法权重是 收藏率 > 核销率 > GMV > 复购率 > 完播率，
> 所以一条 5000 播放 50 收藏的，比 50 万播放 200 收藏的有用得多——后者 99% 的人不在你本地。

### 6. 每周一次的"看别人"（不是每天）

- 每周 1 次，10 分钟：看同城同品类，不看全国爆款
- 每月 1 次：更新场景模板库，把验证过的选题固化下来
- 不追仙侠/赛博朋克/玄幻那类视觉奇观爆款——赛道不同，抄不了也不该抄

## 产出记录示例（脱敏版）

> 以下为一条实际产出记录的脱敏示例，展示 V2 结构的完整用法。

### 第 001 条 · 时令节点

**状态**：待筛选 ｜ **轨道**：稳定线 ｜ **模板**：C 时令 ｜ **类型**：同城互动（20%）

**【给老板】**

出伏了，早晚有点凉。`[本地地标]` 这家店，还是那个 `[核心视觉符号]`。
收藏一下，路过好找。

今天拍这个：把核心产品放桌上，旁边随便摆几颗红枣（超市买的大枣就行），拍一张。
发布时间：上午 10:30 或下午 16:30，二选一，别都发。

发的时候：
1. 抖音「+」→ 选图或选视频 → 下一步
2. 加位置：搜 `[本地地标]` 选上
3. 往下滑，勾上「含AI生成内容」
4. 文案粘上面那段，话题带 `#[本地美食话题]` `#[本地地标话题]` `#[品类话题]` `#[本地探店话题]`
5. 发

**【给你】**

**为什么是这条**：应季元素还没确认，所以今天这条不依赖特定花卉——用大枣做秋季切口。大枣是本地的，秋天正好下市，比花卉更本地，也不怕老板回一句"我家没有"。

**图片提示词**（A段+B段+C段，直接复制）

A 段（永久固定，一个字都别改）：

```
以参考图的产品为唯一主体，产品本体不得重绘：
罐体/杯体颜色、杯型、液体颜色、液面高度、杯中可见配料，
全部与参考图逐项一致，一项都不许变。
罐体/杯体颜色必须与垫图一致：垫图为粉色罐则保持粉色，垫图为透明杯则保持透明，
垫图为白色碗则保持白色，不得擅自改为其他颜色或杯型。
不得添加参考图中不存在的任何配料、水果、谷物、酱料、装饰物。
不得减少或淡化参考图中清晰可见的配料。
不得改变罐子/杯子形状、材质、罐身文字与logo。
AI只负责生成：背景、场景、光线、氛围、构图留白、非食物道具。

手机竖屏实拍质感，自然光，真实生活场景，
镜头轻微手持感，焦外自然虚化，轻微胶片颗粒，
光影过渡自然，颜色饱和度适中不刺眼，
画面有生活痕迹（桌面轻微使用痕迹、背景有虚化的日常杂物）。
```

B 段（本次场景）：

```
北方初秋的午后，[核心产品]放在一张旧木桌面上，
旁边散落着几颗深红色的大枣，一颗开了口的核桃，
背景是虚化的老街巷，斜射的午后阳光带着暖黄色调，
桌面上有树影。
氛围：秋天刚来的感觉，早晚开始凉了，东西实在。
```

C 段（平台参数）：

```
竖屏 9:16，画面右下角留出空白区域
```

**图生视频提示词**：

```
镜头固定不动，只有极轻微的运动，
阳光缓慢移动，树影在桌面轻轻晃动，
2-3片落叶从画面边缘缓缓飘过（不落在产品上），
主体产品全程静止，不发生任何形变，
运动幅度极小，不要转场，不要切镜，不要镜头拉扯，
时长5秒。
```

**筛选要点**：

| # | 看什么 | 不对就弃 |
| --- | --- | --- |
| 1 | 产品颜色对吗 | 变色 → 弃 |
| 2 | 红枣有没有被画进杯里 | 进杯 → 弃。红枣只能是桌上的氛围元素，杯里有什么必须跟实拍一致 |
| 3 | 有乱码字吗 | 有 → 弃 |
| 4 | 1 秒内能看出是你的产品吗 | 认不出、背景抢戏 → 弃 |
| 5 | 看着像真照片吗 | 塑料感、影楼光 → 弃 |

> 第 2 条是这条最容易翻车的地方——AI 特别爱把旁边的食材"顺手"放进杯里。出图后放大看杯口，别只看整体。

**合规判断**：

| 项 | 判断 |
| --- | --- |
| 绝对化用语（最/第一/顶级） | ✅ 无 |
| 功效宣称（瘦身/控卡/排毒/治疗） | ✅ 无 |
| 凭空加料（红枣在杯外） | ✅ 通过 |
| 品牌词 | ✅ 未出现他人品牌名 |
| 需标注「AI生成」+ 勾选「含AI生成内容」 | ⚠️ 待老板执行 |
| 本条未挂团购，暂不需要标「广告」 | ✅ |

**出图参数**：
- 工具：AI 出图工具

- 参考强度：70%（别动这个数）
