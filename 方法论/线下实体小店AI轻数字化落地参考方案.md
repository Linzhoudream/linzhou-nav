# 线下实体小店 AI 轻数字化落地参考方案

> AI 是副驾驶，人是驾驶员。不搞重型 SaaS，优先沉淀自有客户资产，为门店提供多路径进退的决策依据。

## 适用人群

- 加盟型线下实体小店店主（餐饮、茶饮、烘焙等本地生活业态）
- 想用 AI 辅助经营但不知道从哪下手的小老板
- 帮实体店做数字化落地的顾问 / 服务商

## 不适用

- 已有完整数字化系统的大型连锁
- 寻求"全自动无人经营"方案的人——本方案强调人机协作，AI 不替人做决策

---

## 核心概念：一店三态

小店现实会同时面对三种经营状态，AI 统一做数据、内容、客户的打通，同时严格守住合规边界：

1. **加盟期保命运营**：当前阶段优先稳住门店日常经营
2. **抖音 + 企微私域基建**：把平台过路流量沉淀为店铺自有客户资产
3. **转型自营预案（备用兜底）**：仅作为后台预案，不干扰当前加盟经营，参考同类小店转型案例

> **核心目标**：用最小人力成本，把平台过路客转化为私域资产；用真实经营数据辅助经营决策，无论后续选择继续经营、转型、止损，客户资产尽量保留。

## 只抓三件核心事

1. 同城短视频运营，吸引周边到店客流
2. 企业微信私域沉淀，留存到店顾客
3. 极简数据记录，看清真实经营情况

> **AI 定位**：仅生成草稿、做数据分析、输出提醒；所有对外输出内容必须人工确认，AI 不替人做经营决策。

---

## 必须遵守的合规红线

1. **食品宣传合规**：禁止使用「0 蔗糖、无添加、最、第一」等无凭证极限词；AI 生成图文素材需标注「AI 辅助创作」，配料必须和实物保持一致，禁止虚构产品
2. **企微风控**：禁止外挂、批量机器人；控制群发频率，避免账号封禁
3. **加盟商业边界**：加盟存续期间，不擅自改动品牌标识、不泄露品牌配方工艺；转型预案仅做后台储备，不对外传播
4. **数据主权**：客户原始数据保存在自有企微体系；AI 只做计算分析，禁止将客户聊天、消费数据交给第三方模型训练

## 第一周 7 天极简落地 SOP

> 目标：搭建基础底座，每日耗时 10–20 分钟，不增加过重负担；完成基础建设后，再迭代进阶功能。

### Day 1｜同城短视频账号整改

- [ ] 完善账号昵称、简介，标注门店位置、团购入口
- [ ] 隐藏低质、违规旧视频
- [ ] 统一视频封面模板，固定同城话题标签
- [ ] 后续发布视频必须带上门店 POI 定位

### Day 2｜私域基建搭建

- [ ] 开通企业微信外部联系人，生成门店活码
- [ ] 活码放置收银台显眼位置
- [ ] 准备顾客引导话术：到店客户自愿添加私域，可给到小福利，不强求

### Day 3｜建立极简数据记录机制

- [ ] 简易表格，每日记录 3 个核心指标：当日营业额、团购核销数、新增私域客户数
- [ ] 配置 AI 辅助分析：每日打烊后提交数据，获取复盘简报与次日建议（工具类型：通用 AI 对话助手 + 自定义提示词模板，或接入轻量智能体平台）

### Day 4｜发布第一条同城实拍短视频

- [ ] AI 生成选题、脚本、标题作为草稿
- [ ] 实拍门店真实场景，人工出镜口播
- [ ] 发布，带上门店定位与同城话题

### Day 5｜持续输出 + 私域引流

- [ ] 发布第二条短视频
- [ ] 到店引导客户添加企微，设定每日新增目标
- [ ] 录入当日经营数据

### Day 6｜客户维护与内容复盘

- [ ] 回复短视频全部评论
- [ ] AI 生成朋友圈文案草稿，人工确认后再发送
- [ ] 复盘视频数据，优先复制播放效果好的内容形式

### Day 7｜周度复盘

- [ ] 汇总本周核心数据：私域新增、团购核销
- [ ] 总结哪一类内容更受本地用户欢迎
- [ ] 制定下一周简单执行目标

## 进阶模块（第一周完成后再开启）

> 前期不启用，避免负担过重，地基稳固之后再迭代：

1. 客户分层、沉睡客户唤醒
2. 团购套餐优化、小额同城投放测试
3. 轻增值业务探索（合规前提下）
4. 转型自营后台预案：备选名称、菜单方案、客户沟通话术库

## 人与 AI 分工边界

### AI（副驾驶）

| ✅ 做 | ❌ 不做 |
| --- | --- |
| 数据汇总分析 | 自动对外发送消息 |
| 内容草稿生成 | 代替经营决策 |
| 标签识别 | 承诺优惠价格 |
| 风险预警 | 处理投诉退款 |
| 补货建议 | 触碰商业配方隐私 |
| | 使用客户数据训练模型 |

### 店主（驾驶员，最终决策者）

- ✅ 实拍素材
- ✅ 人工审核所有对外内容
- ✅ 客户接待
- ✅ 全部经营决策
- ✅ 日常执行

### 外部顾问 / 方案设计者

| ✅ 做 | ❌ 不做 |
| --- | --- |
| 智能体配置 | 代运营 |
| 合规校验 | 代替执行 |
| 方案迭代 | 接触客户 |
| 陪跑指导 | 干预经营决策 |

## 风险提示

1. **企微风控风险**：批量操作、外挂会造成账号封禁
2. **广告合规风险**：食品行业宣传违规会带来处罚
3. **AI 只是辅助工具**，不能保证经营结果
4. **加盟相关法律问题**，需要参考合同与专业法律意见
