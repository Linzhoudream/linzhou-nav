## 一、GitHub内容更新流程（SOP）

### 流程图

```
内容产生（IMA/腾讯文档/对话）
    │
    ├─ 林舟加标签【公开】或说"记下来"
    │
    ▼
DuMate每日21:00扫描
    │
    ├─ 检测到标记 → 进入脱敏流程
    │
    ├─ 无标记 → 保留在原始位置
    │
    ▼
脱敏检查（5项清单）
    │
    ├─ 通过 → 推送GitHub
    │
    ├─ 不通过 → 标记"待脱敏"，钉钉通知林舟
    │
    ▼
推送GitHub + 更新索引
    │
    ▼
钉钉通知林舟："已推送X文件到Y目录"
```

### 详细步骤

**Step 1：内容产生**

| 来源 | 触发方式 | 谁执行 |
|------|---------|--------|
| IMA笔记 | 标题含【公开】【可发】【脱敏】标签 | 林舟写笔记时加标签 |
| 腾讯文档 | 文档开头或结尾标记"✅ 已完成，可推送" | T/B创作后标记 |
| 对话中 | 林舟说"记下来""这个可以公开""推到GitHub" | DuMate记录 |
| 模拟实战 | 产出"实战记录#N"文件 | DuMate整理后推送 |
| 客户交付 | 林舟说"这个案例可以脱敏公开" | DuMate生成案例文件 |

**Step 2：检测触发**

- **定时扫描：** DuMate每天21:00执行一次
  - 扫描IMA笔记标题（关键词：公开/可发/脱敏）
  - 扫描腾讯文档标记（✅ 已完成）
  - 检查待推送队列（对话中记录的事项）

- **事件驱动：** 林舟明确说"现在推"
  - 立即执行，不走定时
  - 适用于紧急事项

**Step 3：脱敏检查（必做）**

| 检查项 | 标准 | 不通过处理 |
|--------|------|-----------|
| 真实人名 | 是否出现具体人名（非化名） | 替换为[某人]或化名 |
| 具体工厂/商家 | 是否出现真实企业名称 | 替换为[工厂A]或脱敏 |
| 具体金额 | 是否出现真实交易金额 | 模糊化（"数百元""数千元"） |
| 个人隐私 | 是否含家庭/健康/地址信息 | 删除或替换 |
| API密钥/Token | 是否含密钥、密码、Token | **绝对删除**，只保留描述 |
| 未公开策略 | 是否含未执行的策略/计划 | 删除或标记为内部 |
| 内部协作细节 | 是否含AI分工/定时任务细节 | 删除或模糊化 |

**Step 4：推送GitHub**

1. 确定目标目录（见"目录规范"）
2. 确定文件名（见"命名规范"）
3. 生成Markdown文件
4. 调用GitHub API推送
5. 验证推送成功（读取确认）

**Step 5：更新索引**

- 更新 `IMA可推送GitHub文件清单`（标记状态）
- 更新 `IMA-GitHub镜像索引`（记录文件位置）
- 如影响首页展示，更新 `README.md`

**Step 6：通知**

- 钉钉发消息："【GitHub更新】已推送《文件名》到《目录》，脱敏检查：通过/待确认"
- 如脱敏不通过：钉钉发消息："【需确认】《文件名》含《具体问题》，请确认是否脱敏后推送"

## 四、脱敏检查清单（推送前必读）

### 绝对禁止项（红线）

- [ ] API密钥、Token、密码（任何格式）
- [ ] 林舟家庭住址、亲属信息
- [ ] 林舟健康细节（具体疾病、用药）
- [ ] 未公开的商业合作（在谈但未定）
- [ ] 具体客户的真实信息（未经脱敏）

### 需要模糊化项

- [ ] 具体工厂名称 → 替换为[工厂A]或行业描述
- [ ] 具体人名 → 替换为化名或[某人]
- [ ] 具体金额 → 模糊为区间（"数百元""几千元"）
- [ ] 具体时间地点 → 保留月份，模糊日期

### 可以保留项

- [x] 行业通用数据（白沟出口额、拼多多规则）
- [x] 方法论框架（15分钟验证法、决策框架）
- [x] 工具使用经验（秒哒应用、AI生图技巧）
- [x] 公开可查的政策（金税四期、AI标注新规）

## 六、FAQ

**Q1：我不知道这个能不能公开，怎么办？**
A：先不加标签，留在IMA。DuMate每周一扫描时会标注"待确认"，你确认后再推。

**Q2：推送后发现内容有误，怎么修改？**
A：在IMA修改源文件→重新加【公开】标签→DuMate检测到变化→重新推送（GitHub会自动版本控制，旧版本保留）。

**Q3：T/B创作的内容，什么时候推？**
A：T/B标记"✅ 已完成"后，DuMate每天21:00扫描。如紧急，林舟说"现在推"立即执行。

**Q4：AI换对话框后，怎么知道这个流程？**
A：所有AI启动时，先读取 `GitHub/索引/GitHub更新SOP.md`。不依赖记忆，依赖文件。

**Q5：IMA推不进去怎么办？**
A：IMA API不稳定，当前方案：
1. 你写IMA笔记时加标签
2. DuMate扫描读取（API可用时）
3. 如API不可用，你手动复制到腾讯文档或GitHub
4. 长期方案：考虑IMA→Obsidian本地迁移
